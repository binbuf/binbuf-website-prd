Gen VST

A Sega Genesis inspired VST3/AU/CLAP audio plugin emulating legendary audio FM synth and PSG chips (YM2612/SN76489).

3D & Audio · Windows · macOS · Linux

Download for your DAW Source on GitHub
v0.3.4 Windows · macOS · Linux VST3 · AU · CLAP · Standalone GPL-3.0

Installers are not code-signed yet


What's inside

FM mode — YM2612

Six-operator FM with 16-voice polyphony, a hardware-style operator grid and all four FREQ CTRL modes (INT, FLOAT, AUTO RETRIG).

SQ mode — SN76489

Three tone channels plus a noise channel, each with its own ADSR, detune and pan.

D mode — the 8-bit DAC

An audio FX chain for your own tracks: sample-rate decimation, 8-bit quantization, mono and dry/wet. Not a sampler.

Presets that go deep

About 40 original FM patches, 47 community FM patches from Furnace’s tfilib, and 12 hand-tuned PSG presets in a tagged, folder-based browser.

Loads your libraries

.tfi, .vgi, .dmp, .y12, .opm, .vgm and .psg patches, with automatic mode switching. Drag folders onto the window.

Validated like hardware

201 unit tests and pluginval --strictness-level 8 on Windows VST3 before release.

Getting started

1

Install for your platform

Windows: .exe installer. macOS: .pkg (Apple silicon or Intel). Linux: .tar.gz for VST3 + CLAP or an AppImage for standalone.

2

Clear the unsigned warning

Windows: SmartScreen → More info → Run anyway. macOS: System Settings → Privacy & Security → Open Anyway. Linux: install libwebkit2gtk-4.1-0 if it is missing.

3

Rescan and play

Rescan plugins in your DAW, drop Gen VST on a track, and start from a factory patch — or load a bank you already own.

Modes

ModeChip and character
FMYM2612 via ymfm. Six-operator FM, 16-voice polyphony, bass, bells, brass, drums and leads.
SQSN76489 via libvgm. Three square-wave tone channels plus noise — the bright, simple voice of the console.
DPure DSP. Decimation, 8-bit quantization and mono for your own audio. An effect, not an instrument.

Under the hood

A modern plugin on real emulation cores.

Gen VST pairs authoritative chip emulation with a WebView UI, so the interface can be as detailed as the DSP without slowing the audio thread.

Emulation first, interface second.

The audio path is a single C++20 / JUCE 8 plugin: ymfm for the YM2612, libvgm’s SN76489 core, and a pure-DSP chain for D mode and the shared output bus. The UI is HTML/CSS/JS bundled by Vite and rendered through JUCE’s WebView component, with a two-way bridge to the parameter tree.

  • ymfm (BSD-3) — and ValleyBell/libvgm (LGPL/BSD) for the chip cores
  • JUCE 8 WebView UI — on WebView2, WKWebView and WebKitGTK
  • 16-voice pool — with LRU voice stealing and Poly, Mono and Unison modes
  • Folder-rooted patch browser — with lazy scanning and a background index
  • Design docs and ADRs — live in the repository alongside the code

Gen VST FAQ

Before you install.

Which plugin formats do I get?

VST3 and CLAP on Windows, macOS and Linux; AU on macOS; and a standalone app on all three platforms.

Is Gen VST free?

Yes. It is released under GPL-3.0, and the source is public on GitHub.

Is D mode a sampler?

No. D mode is an audio effect: it runs the track’s audio through Genesis-style sample-rate decimation, 8-bit quantization, mono summing and a dry/wet control.

Do I need the original console or an emulator?

No. The YM2612 and SN76489 emulation is inside the plugin, and it runs as VST3, AU, CLAP or standalone on your computer.

Are game soundtracks included?

No game-derived patches are distributed. The factory banks are original and community patches with generic names. You can import your own banks from .tfi, .dmp, .vgm and similar files in the plugin browser.

Why does macOS or Windows warn about the installer?

The installers are not code-signed yet. Windows may show SmartScreen and macOS Gatekeeper will ask once; the README documents the exact steps, including the System Settings path on macOS Tahoe.
