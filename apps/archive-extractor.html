Archive Extractor

A tiny, premium Windows extractor app, inspired by macOS.

Files & Data · Windows

Download for Windows Source on GitHub
v0.1.1 Windows 10/11 · x64 Native C++20 Free

What's inside

Every major archive format

ZIP, 7z, RAR and TAR containers; gz, bz2, xz, zst, lz4 and br streams; tar.gz-style compounds; and multi-volume 7z, RAR and spanned ZIP sets.

Smart placement

Files land in a sensibly named folder next to the archive instead of scattering across Downloads.

Passwords welcome

Encrypted ZIP, header-encrypted 7z and RAR/RAR5 all prompt for a password — including split archives.

Reveal and select

When extraction finishes, Explorer opens with the new files already selected, so the next step is obvious.

Featherweight

Statically linked with no VC++ redistributable and no installer prerequisites. Nothing to set up before it works.

Getting started

1

Download the release

Grab the latest build from Releases and keep the executable somewhere permanent, like C:\Tools.

2

Associate the formats

Point the archive extensions at ArchiveExtractor.exe once in Windows Settings → Default apps. Building from source? The repo tooling can register the associations for you.

3

Double-click anything

ZIP, 7z, RAR, TAR, gz — double-click and it extracts itself. Enter a password if the archive asks for one.

Under the hood

A macOS inspired archive extractor for Windows

Quickly and easily extract nearly any archive.

  • C++20 · Win32 — a native front end with no framework runtime
  • libarchive — with zlib, bzip2, lzma, lz4, zstd and OpenSSL for stream formats
  • bit7z / 7z.dll — for encrypted 7z and RAR archives, plus Brotli for .br
  • Pinned vcpkg baseline — so every clone resolves the same dependency versions
  • GoogleTest + CTest — with a PowerShell build script that builds and tests in one step

Archive Extractor FAQ

Which archive formats can it extract?

ZIP, 7z, RAR and TAR containers; gz, bz2, xz, zst, lz4 and br streams; tar.gz-style compounds; and multi-volume 7z, RAR and spanned ZIP sets.

Is Archive Extractor free?

Yes. It is free to download and use, the full source is published on GitHub, and releases bundle no ads, no toolbars and no third-party installers.

Does it work offline?

Completely. Extraction uses bundled libraries, and the app makes no network requests.

Can I choose where files are extracted?

By design, no. Files are placed in a sensibly named folder next to the archive, and you can move or rename it like any other folder.

Which archives can ask for a password?

Encrypted ZIP, 7z (including header-encrypted archives) and RAR/RAR5. Multi-volume sets that are encrypted also prompt.

Does it need an installer or runtime dependencies?

No. It is a single statically linked executable with no VC++ redistributable and no installer prerequisites, so you can keep it anywhere on disk.

Will it change my file associations without asking?

No. Associations are a one-time setup step you perform, either in Windows Settings or with the repository’s build tooling for a local build. Nothing changes silently.
