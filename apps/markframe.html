markframe FAQ

Does markframe generate real app code?

Not today. It renders high-fidelity previews for prototyping and review; exporting templates to functional UI boilerplate is on the roadmap.

Is markframe free?

Yes. It is MIT licensed, and the source is public on GitHub.

Where are my files stored?

Locally, through the browser’s File System Access API. Screens are saved as .mf files on your disk, and nothing is uploaded.

Which browsers work?

Chrome, Edge and Safari 16 or later support local file open and save. The editor and preview work in any modern browser.

Can I use it offline or self-host it?

Yes. It is a static single-page app: load it once and keep the tab, or build the repository and host the output anywhere.

Is markframe just for AI-generated screens?

No. It is a fast prototyping format on its own, and a login screen takes six lines. It is designed so that LLM-generated markup is also easy for humans to review.
